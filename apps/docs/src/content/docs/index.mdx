<CardGrid>
  <Card title="@sororail/sdk" icon="document">
    Clients for all five contracts, typed error decoding, Freighter and keypair
    signers, and amount helpers. Every stage of a call (prepare, simulate, sign
    and send) is separately accessible, so a screen can show what a transaction
    will do before anyone signs it.
  </Card>
  <Card title="Reference app" icon="setting">
    A Next.js app with overview, payroll, streams, vesting and escrow screens,
    built on the SDK and signing through Freighter. It is entirely client-side
    against Soroban RPC.
  </Card>
  <Card title="Contracts" icon="open-book">
    The Soroban contracts live in
    [Sororail/sororail-contracts](https://github.com/Sororail/sororail-contracts).
